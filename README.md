# HI-XR 2027 — Healthcare Intelligence and eXtended Reality

Single-page website for the HI-XR workshop at IEEE AIxVR 2027.

## Files

- `index.html` — the whole site (HTML + CSS, no build step)
- `assets/img/` — images
- `.nojekyll` — tells GitHub Pages to serve files as-is

## Publish on GitHub Pages

1. Create a repository (e.g. `hi-xr-2027`) and push `index.html`, `assets/`, `.nojekyll` and this README to the `main` branch.
   The `2026/` folder and the proposal `.docx` are source material and don't need to be published.
2. In the repository, go to **Settings → Pages**, set **Source** to *Deploy from a branch*, branch `main`, folder `/ (root)`.
3. The site will be live at `https://<username>.github.io/hi-xr-2027/` within a minute or two.
